Prerequisits
  node 20.x , expo 54.x
  Java 17.x
  Android sdk 36+npm in
Installation
  After setting up prerequisitions go to the project directory and run** npm install**
  Check with following commands
  run **npx expo-doctor**
    it should say no issues detected
  **npx expo install --check**
    it should say all dependencies are upto date
  
Expo Commands
  install any npm packages on top of this using npx **expo install**
  To run the app 
    npx expo start 
    or 
    npx expo start -c (to clear the cache and run)
  Then 
    You can either scan the qr code that is displayed using expo app on mobile with usb connected and usb debugging on mobile
    or 
    run on web/desktop browser by typing **w**
